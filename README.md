# Studdy 🎓

A social network for students worldwide to connect, 
ask questions and get answers from peers in their exact field of study.

## Tech Stack
- Frontend: React, Tailwind CSS
- Backend: PHP / Symfony, REST API
- Database: MySQL

## Getting Started

### Prerequisites
- Node.js 18+
- PHP 8.1+
- Composer
- MySQL

### Installation
git clone https://github.com/FaBo1235/studdy
cd studdy
cp .env.example .env    # puis remplis les variables
npm install
composer install
npm run dev
